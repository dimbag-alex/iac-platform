# IaC Platform
Платформа для управления жизненным циклом инфраструктуры как кода (IaC) с веб-интерфейсом и REST API.

## Модули
- backend — компоненты управления жизненным циклом инфраструктуры
- frontend — клиентская часть
- modules/automation — интеграция с инструментами автоматизации
- db — проектирование БД
- Git — хранение и версионирование кода проекта
